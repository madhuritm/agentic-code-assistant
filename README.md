# Agentic Code Assistant

A hands-on implementation of an agentic coding assistant, built while learning how to design modular, scalable, and production-oriented Agentic AI systems.

## About This Project

This repository documents my hands-on work while taking the Agentic AI System Design course from Educosys, taught by Keerti Purswani.

One of the course capstone projects involves building a Claude Code-like coding agent. The instructor provides the architecture, demonstrations, and much of the core implementation. I am rebuilding the project alongside the course so that I can understand each component by implementing it myself rather than only watching the demonstrations.

My goal is to use this repository to document my progress, experiment with the concepts being taught, and develop a deeper understanding of the engineering behind production-grade agentic AI systems.

## What I'm Exploring

As I progress through the project, I’ll be working with concepts including:

Modular agent architecture
Agent creation and factory patterns
Context management
Code indexing and retrieval
Retrieval-Augmented Generation (RAG) for codebases
Code-aware text splitting
Vector search with Qdrant
Agent evaluation
Observability
Configuration management
Tool use and agent workflows
Scalable and maintainable AI system design
STM, LTM
MCP

## Why I'm Building It

I believe strong software engineering practices are especially important as AI applications move from prototypes into production.

It is relatively easy to connect an LLM to a few tools and create an impressive demo. Building an AI system that is modular, observable, maintainable, scalable, and performant is a much more interesting engineering problem.

This project is an opportunity for me to study those problems hands-on and apply established software engineering principles to agentic AI development.
